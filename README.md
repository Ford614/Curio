# Curio - マウスカーソル一括インストーラー

`Curio` は Windows 10 / 11 向けのマウスカーソル一括登録 GUI アプリケーションです。  
Web配布サイトからのダウンロード自動検出、ドラッグ＆ドロップ、Windowsのファイル関連付け（プログラムから開く）などの様々な経路から、フォルダ内にある大量の `.cur` / `.ani` / `.zip` ファイルを自動検出・キーワード分類し、Windowsの「マウスのプロパティ → ポインター → デザイン」から選択可能な**カーソルスキーム（デザイン）**として安全に一括登録・管理することができます。

---

## 🔥 主な特徴

1. **🌐 Webから直接カーソルを追加 (WebView2内蔵)**
   - Curio内に組み込まれたWebブラウザで、カーソル配布サイトを閲覧・ダウンロード。
   - `.cur` / `.ani` / `.zip` のダウンロードを自動検知し、一括登録画面へワンクリックで連携。
2. **📥 直感的なドラッグ＆ドロップ対応**
   - Windowsのエクスプローラーから `.cur` / `.ani` / `.zip` やフォルダをCurioウィンドウへ直接ドラッグ＆ドロップして取り込み可能。
3. **🔗 Windowsファイル関連付け・「プログラムから開く」「送る」対応**
   - ファイル右クリックの「プログラムから開く」や「送る」メニュー、またはコマンドライン引数からCurioで直接開いてインポート。
4. **🛡️ 厳格な統合セキュリティ (`ImportService`)**
   - `.exe`, `.msi`, `.bat`, `.cmd`, `.ps1` などの実行可能ファイルは**絶対に実行・保存せず自動遮断**。
   - **Zip Slip攻撃防御**: ZIP展開時のディレクトリトラバーサル試行を厳格にブロック。
   - ファイルサイズ上限チェック（50MB上限）。
5. **自動検出 & キーワードマッピング**
   - ファイル名（英語・日本語）から Windows 標準の 15～17 のカーソル役割（通常、ヘルプ、待ち時間、テキスト選択等）へ自動割り当て。
6. **カーソルプレビュー機能**
   - `.cur` および `.ani` のプレビュー画像をアイコン付きで一覧表示。
7. **管理者権限 (UAC) 不要**
   - ユーザー単位のレジストリ (`HKCU\Control Panel\Cursors\Schemes`) および指定保存先フォルダを使用するため、管理者権限なしで安全に利用可能。
8. **保存先フォルダの設定機能**
   - 一括インストールするカーソル実体ファイルの保管フォルダを自由に変更・リセット可能（デフォルト: `%LOCALAPPDATA%\Curio\Schemes\`）。
9. **アンインストール・一覧管理**
   - 登録済みスキームを一覧表示し、クリックで選択して「今すぐ適用」や「スキーム削除」（アンインストール）が簡単に行えます。
10. **即座に反映**
   - インストール後に Windows 全体へスキーム設定を即時反映（`SystemParametersInfo` によるリアルタイム更新）。

---

## 🛠️ 動作環境

- **OS**: Windows 10 / Windows 11 (64-bit / 32-bit / ARM64)
- **ランタイム**: .NET 8.0 または .NET 10.0 Desktop Runtime (WPF) + WebView2 Runtime

---

## 📖 使い方

### 1. Webからカーソルを追加する

1. 「🌐 Webでカーソルを探す」タブを開きます。
2. ナビゲーションバーで配布サイトを開き、通常通りカーソルファイル（.cur / .ani / .zip）をダウンロードします。
3. ダウンロードが完了すると右下に通知トーストが表示されます。「一括登録画面で開く」をクリックします。

### 2. ドラッグ＆ドロップで追加する

1. エクスプローラーから `.cur`, `.ani`, `.zip` ファイルやフォルダをCurioウィンドウへドロップします。
2. 自動的にインポート処理が走り、役割割り当て画面へセットされます。

### 3. 「プログラムから開く」関連付け

1. アプリ画面右上の「🔗 ファイル関連付け登録」ボタンをクリックします。
2. 関連付け完了後、`.cur`, `.ani`, `.zip` を右クリックしてCurioで開くことができるようになります。

## 📁 レジストリおよび保存先の仕様

- **レジストリ登録箇所**:  
  `HKEY_CURRENT_USER\Control Panel\Cursors\Schemes`
- **デフォルト保存先**:  
  `%LOCALAPPDATA%\Curio\Schemes\<スキーム名>\`
- **一時ファイル保存先**:  
  `%LOCALAPPDATA%\Curio\Downloads\` 及び `%LOCALAPPDATA%\Curio\TempExtract\`
