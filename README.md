# マウスカーソル一括インストーラー (Mouse Cursor Batch Installer)

Windows 10 / 11 向けのマウスカーソル一括登録 GUI アプリケーションです。  
指定したフォルダ（およびサブフォルダ）内にある大量の `.cur` / `.ani` ファイルを自動検出・キーワード分類し、Windowsの「マウスのプロパティ → ポインター → デザイン」から選択可能な**カーソルスキーム（デザイン）**として一括登録・管理することができます。

---

## 🔥 主な特徴

1. **GUI アプリケーション (C# + WPF)**
   - モダンで分かりやすい操作画面を提供。
2. **自動検出 & キーワードマッピング**
   - `.cur` (静止カーソル) および `.ani` (アニメーションカーソル) を自動検出。
   - サブフォルダ内のファイル検索・再帰検索に対応。
   - ファイル名（英語・日本語）から Windows 標準の 15～17 のカーソル役割（通常、ヘルプ、待ち時間、テキスト選択等）へ自動割り当て。
3. **カーソルプレビュー機能**
   - `.cur` および `.ani` のプレビュー画像をアイコン付きで一覧表示。
4. **管理者権限 (UAC) 不要**
   - ユーザー単位のレジストリ (`HKCU\Control Panel\Cursors\Schemes`) および指定保存先フォルダを使用するため、管理者権限なしで安全に利用可能。
5. **保存先フォルダの設定機能 (新機能)**
   - 一括インストールするカーソル実体ファイルの保管フォルダを自由に変更・リセット可能（デフォルト: `%LOCALAPPDATA%\MouseCursorInstaller\Schemes\`）。
6. **元ファイルを変更・削除しない安全設計**
   - 元のカーソルファイルは複製してアプリ指定フォルダに保存するため、元のファイルを移動・削除してもスキームが壊れません。
7. **複数スキームの登録 & 同名確認**
   - 任意のスキーム名で登録可能。同名のスキームが存在する場合は「上書き保存」「別名保存」「キャンセル」を確認するダイアログを表示。
8. **アンインストール・一覧管理**
   - 登録済みスキームを一覧表示し、クリックで選択して「今すぐ適用」や「スキーム削除」（アンインストール）が簡単に行えます。
9. **即座に反映**
   - インストール後に Windows 全体へスキーム設定を即時反映（`SystemParametersInfo` によるリアルタイム更新）。
10. **エラー耐性 & ログ表示**
   - 一部のファイルで読み込みエラーや破損があっても、他のファイルの処理をスキップして継続。
   - 画面下部のログパネルに処理結果をリアルタイム表示。

---

## 🛠️ 動作環境

- **OS**: Windows 10 / Windows 11 (64-bit / 32-bit / ARM64)
- **ランタイム**: .NET 8.0 または .NET 10.0 Desktop Runtime (WPF)

## 🚀 ビルド方法

### コマンドラインでのビルド

1. **プロジェクトフォルダへ移動**
   ```powershell
   cd s:\Work\Program\Projects\App\MouseCursorCustom
   ```

2. **リリースビルドの実行**
   ```powershell
   dotnet build -c Release
   ```
   ビルド成果物は `bin\Release\net10.0-windows\MouseCursorCustom.exe` に出力されます。

3. **単一 EXE ファイルとしてのパブリッシュ (配布用)**
   ```powershell
   dotnet publish -c Release -r win-x64 --self-contained false /p:PublishSingleFile=true
   ```

## 📖 使い方

### 1. カーソルの一括登録

1. `MouseCursorCustom.exe` を起動します。
2. 「入力フォルダパス」の「参照...」ボタンをクリックし、カーソルファイル (`.cur` / `.ani`) が入ったフォルダを選択します。
3. 必要に応じて「📁 保存先フォルダ」を変更・指定します（「初期値に戻す」でデフォルトに戻せます）。
4. 「🔍 カーソル検索」をクリックすると、フォルダ内からカーソルを検出します。
5. 各役割にファイルが自動セットされます。必要に応じて個別に変更できます。
6. 「⚡ 一括インストール」をクリックします。

### 2. 登録済みスキームの管理・適用・削除

1. メイン画面の「⚙️ 登録済みスキーム管理」タブを開きます。
2. Windows（レジストリ）に登録されているカーソルスキームを選択します。
3. 「今すぐ適用」で選択したスキームをWindowsカーソルに反映、「❌ 選択したスキームを削除」でアンインストールします。

---

## 📁 レジストリおよび保存先の仕様

- **レジストリ登録箇所**:  
  `HKEY_CURRENT_USER\Control Panel\Cursors\Schemes`
- **デフォルト保存先**:  
  `%LOCALAPPDATA%\MouseCursorInstaller\Schemes\<スキーム名>\` （画面上から自由に変更可能）
